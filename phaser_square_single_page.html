Year 12 Phaser Game: Square Collector

A simple one-page Phaser game using shapes only — no sprite files needed.

Student task

Control the green square. Collect all the yellow coins. Avoid the red squares.

←→↑↓ WASD
Challenge 1: Change the player speed.
Look for playerSpeed in the JavaScript.
Challenge 2: Add more coins or obstacles.
Look for the coinPositions and obstaclePositions arrays.
Challenge 3: Change the game rules.
Could touching a red square lose 2 points instead of restarting?
How the game works

The game is made from rectangles and circles using Phaser graphics. The player is a square with physics enabled. Coins and obstacles are also physics objects, but they do not move.

The update() function runs many times per second. It checks the keyboard and changes the square’s velocity.

Key Phaser ideas
  • config sets up the game size, physics and scene.
  • preload is empty because this version uses shapes, not image files.
  • create builds the player, coins, obstacles and text.
  • update checks input every frame.
